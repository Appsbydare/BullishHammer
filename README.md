# Bullish Hammer

Bullish Hammer is a premium retail FX trading and market analysis publication. The platform is built on a modern Next.js 15+ frontend, integrated with a headless Sanity CMS backend, and features a fully automated, AI-driven content ingestion pipeline.

## System Architecture

The project is structured as a monorepo to maintain tight coupling between the frontend and the content schemas:
* `/web`: A Next.js 15+ application using the App Router. This handles the public-facing publication and a secured administrative dashboard.
* `/studio`: A Sanity CMS (v3) instance for content management and structured data definition.

### Core Workflows

1. **AI Content Generation (`web/generate-article.js`)**
   A dedicated Node.js ingestion engine fetches live market data from the Marketaux API and processes it through Google Gemini to generate professional financial articles. The resulting structured data is submitted to the Next.js `/api/ingest` endpoint using a secure bearer token.

2. **Editorial Content Flow**
   Articles generated by the AI pipeline are ingested as `draft` documents. Administrators can access the secured `/admin` dashboard to review these drafts, apply edits, and publish them to the live site. The admin interface is protected via secure session cookies.

3. **Ad Placement and Management**
   Sponsor campaigns and advertisement banners are managed natively within Sanity. These assets are dynamically injected into designated slots within the article detail pages based on active campaign dates.

## Setup and Installation

### Prerequisites
* Node.js 18 or higher
* Sanity CLI (optional but recommended for schema development)

### Environment Configuration

Create a `.env.local` file in the `web` directory with the following variables:

```env
# Sanity CMS Configuration
NEXT_PUBLIC_SANITY_PROJECT_ID=cx58gblo
NEXT_PUBLIC_SANITY_DATASET=production
SANITY_API_WRITE_TOKEN=your_sanity_editor_token

# External API Integrations
CURRENCYFREAKS_API_KEY=your_currencyfreaks_key
MARKETAUX_API_TOKEN=your_marketaux_token
POLLINATIONS_API_KEY=your_pollinations_key

# AI Configuration
GEMINI_API_KEY=your_google_gemini_key
GEMINI_MODEL=gemini-2.5-flash-lite
IMAGE_GEN_MODEL=flux

# Application Security
ADMIN_PASSWORD=your_admin_login_password
AI_INGEST_SECRET=your_secure_ingestion_token
NEXT_PUBLIC_SITE_URL=http://localhost:3000
```

### Running the Application

1. Install all dependencies from the root of the project:
   ```bash
   npm install
   ```

2. Start the development servers. This will run the Next.js application on port 3000 and Sanity Studio on port 3333 concurrently:
   ```bash
   npm run dev
   ```

3. To manually trigger the AI article generation pipeline, run:
   ```bash
   cd web
   node generate-article.js
   ```

## Development Guidelines

### Styling Architecture
* The project strictly uses vanilla CSS located in the global stylesheet (`web/src/app/globals.css`) and the admin stylesheet (`web/src/app/admin/admin.css`).
* Tailwind CSS and other utility-first frameworks are intentionally excluded from this project to maintain the custom design system.

### Security Implementation
* The administrative dashboard uses a custom session-based authentication mechanism.
* Secure HTTP-only cookies are utilized for session persistence, configured to expire after one week of inactivity.
* Production deployments require the `NEXT_PUBLIC_SITE_URL` environment variable to ensure proper routing for the ingestion API.
